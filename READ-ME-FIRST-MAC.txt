PIXEL POMO DEV KIT - macOS
==========================

See your own sprite or voxel model standing in Pixel Pomo's garden.

NOTE: this is the first Mac build. It was built and started on GitHub's
Macs, with no window; nobody has yet opened it on a Mac with a screen. If a
step below does not go as written, what happened instead is worth reporting
exactly.


INSTALL IT

  1. You downloaded PixelPomoDevKit-macos-....zip and this file was in it,
     so there is now a folder called PixelPomoDevKit-macos-... in Downloads.
     (Which zip: Apple menu > About This Mac. "Chip: Apple M..." is
     apple-silicon; "Processor: ... Intel ..." is intel.)

  2. Do NOT double-click the app yet. The Dev Kit is not signed with a paid
     Apple developer account, so macOS refuses to open it straight from a
     download ("Apple could not verify..."). One line removes that mark and
     opens it. Open Terminal (Cmd + Space, type "Terminal", Enter), paste
     this line and press Enter:

    cd ~/Downloads && xattr -dr com.apple.quarantine PixelPomoDevKit-macos-* && open PixelPomoDevKit-macos-*/PixelPomoDevKit.app

     Nothing is printed when it works. The setup window opens.

  3. The setup asks where the Dev Kit should live and suggests

      /Applications/PixelPomoDevKit

     Press INSTALL, then OPEN THE DEV KIT. Do not choose Documents, Desktop
     or Downloads: those are the three folders macOS asks permission for.

  4. From now on open it from /Applications/PixelPomoDevKit - drag the app
     to the Dock to keep it there. The folder in Downloads can go in the
     Trash.


IF YOU ALREADY DOUBLE-CLICKED IT AND macOS SAID NO

  Nothing is broken. Click Done on the warning (not "Move to Trash"), then
  run the line above - or, without Terminal: System Settings > Privacy &
  Security, scroll down to "PixelPomoDevKit was blocked", click Open Anyway
  and confirm.


IF TERMINAL SAYS "No such file or directory"

  The download is not in Downloads, or is still a .zip: double-click the
  .zip first. If you keep it somewhere else, type

      xattr -dr com.apple.quarantine

  and a space, drag the PixelPomoDevKit app from Finder onto the Terminal
  window, press Enter, and then double-click the app.


THE ONE-LINE INSTALL (only once the kit's repository is public)

    curl -fsSL https://github.com/hero-999-dev/pixel_pomo_dev_kit/releases/latest/download/install-mac.sh | sh

  It picks the right build, fetches it and opens the setup: no download to
  unzip, no warning to get past. While the repository is private the line
  cannot reach the files, and says the download failed.


USE IT

  1. ADD > ADD 2D SPRITE     a .png from the Art Kit ("Export engine sprite")
     ADD > ADD 3D VOX FILE   a .vox saved from MagicaVoxel - the model is
                             shown as you choose its size and its turn
  2. Pick it on the shelf at the bottom. It is marked NEW.
  3. Click a tile in the garden. Click the tile again to take it off.

  Right-click (two-finger click) anything on the shelf for its details; for
  something you added: CHANGE and MOVE TO TRASH. TRASH, top right, puts a
  thing back or deletes it for good.

  Right mouse button + drag turns the garden. Scrolling zooms. VIEW switches
  between the browser look and a phone's screen. GUIDE has the rest.


YOUR FILES

  Everything you add is kept, each file under its own name, in

      /Applications/PixelPomoDevKit/Files/      (or the folder you chose)

  beside the app, not inside it - and not in Documents, so macOS never asks
  for permission. Click the version number, top left in the kit, to see the
  folders and open them.


UPDATES

  UPDATE, top right, says when a newer version is out. Click it: the kit
  downloads it, closes, and opens again as the new version. It replaces the
  app only; the Files folder is not touched. (It can only look for versions
  once the kit's repository is public. Until then, a newer download opened
  the same way as above updates the installed kit and keeps your files.)

  devkit.log in the Files folder says what went wrong if the kit misbehaves.
