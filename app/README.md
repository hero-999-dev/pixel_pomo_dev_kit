# The Dev Kit's page

The screen of the Dev Kit, as a Flutter web build: the game's garden engine
(`package:pixel_pomo`, by path from `..\..\App\flutter`), the bar, the shelf and
the dialogs. The launcher in `..\dev_kit` serves it and keeps the artist's files.

`assets/` is not kept here — `..\sync_assets.py` copies it from the game before
every build. Build and run through `..\build.py` or `Terminal\dev-kit.ps1`; see
`..\README.md`.
