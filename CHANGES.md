# What changed

The first lines under each version are what the kit's UPDATE panel shows under
WHAT CHANGED, and what a release page opens with (`release_notes.py`). Written
for the artist using the kit: what is different on the screen, not how.

## v0.1.4

- **TURN.** Each model you place keeps its own angle. Pick a 3D model and set
  TURN, at the right of the line under the garden — the arrows, the Q and E
  keys, or a number from 0 to 360 — then click a tile. The next one can go
  down at another angle; the ones already placed stay as they are.
- Click a placed copy with a different TURN set and it turns where it stands.

## v0.1.3

- The setup no longer stops at "Starting... 0%" when it installs into
  Program Files.

## v0.1.2

- The setup shows what it is doing: a bar, and the step in words.
- If Windows' permission question opens behind the window, the setup says
  where to look for it. CANCEL always ends the setup.

## v0.1.1

- The Dev Kit installs like a program: it asks where, suggests Program Files,
  and puts a shortcut on the Desktop. Everything you add is kept in `Files`
  inside that folder, each file under its own name.
- ADD 3D VOX FILE shows the model as you choose its size (wide x long tiles,
  typed) and its turn (0 to 360).
- Right-click anything on the shelf for its details, CHANGE and MOVE TO TRASH.
- UPDATE and TRASH, top right. Click the version number to see where your
  files are.
